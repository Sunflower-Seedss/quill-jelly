# Quill Jelly

An interactive 3D jelly Quill, built with native WebGPU and WGSL shaders, with volumetric XPBD soft-body physics.

Drag to stretch, release to wobble. Shift-drag or use two fingers to twist. Controls include firmness, damping, color presets, quarter speed, mesh view, pause and reset.

Open in a browser with WebGPU support. No installation, external assets, or dependencies.
